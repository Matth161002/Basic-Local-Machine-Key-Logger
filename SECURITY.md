# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in Basic-Local-Machine-Key-Logger, please do not report it through a public GitHub issue.

I would appreciate it if security issues were reported privately so that I have an opportunity to investigate and address them before details are made public.

When reporting a vulnerability, please include:

- A description of the issue
- The version or commit where you found it
- Steps to reproduce the issue
- Any relevant logs, screenshots or other information that may help with the investigation

I will review reported vulnerabilities and address them where appropriate.

## Responsible Use

Basic-Local-Machine-Key-Logger is intended for personal learning, experimentation and use on systems that you own or have permission to monitor.

Please ensure that you have appropriate authorisation before using the software to capture or inspect keyboard input. I am not responsible for misuse of the software or for use that violates applicable laws, regulations or organisational policies.
