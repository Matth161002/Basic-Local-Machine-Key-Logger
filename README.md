# Basic Local Machine Key Logger

A small Python project for learning about keyboard event monitoring with pynput.

## Current Project

The project currently contains a simple Python script for experimenting with keyboard input events.

## Requirements

- Python 3
- pynput

Install the dependency with:

```powershell
pip install pynput
```

## Usage

Run the Python script with:

```powershell
python Keylogger.py
```

## Development

This is a personal project that will be developed further as I explore keyboard event handling and desktop security concepts.
